# Cronograma Geral de Manutenção Preventiva - Unidade MGCEN00

Painel interativo e inteligente para planejamento de manutenção preventiva de sistemas de climatização (HVAC), refrigeração e infraestrutura elétrica da unidade MGCEN00.

## 🚀 Funcionalidades

- **Gerenciamento Semanal e Diário**: Visualização de cronograma de 11 linhas horárias (08:00 às 18:00) com horário de almoço fixo (12:00 às 13:00).
- **Cartões Inteligentes de Tarefas**: Edição multi-linha de títulos e descrições com ajuste dinâmico de altura e atalho Enter.
- **Sistema Anti-Colisão**: Prevenção em tempo real de sobreposição de tarefas durante arrasto, redimensionamento, criação e colar.
- **Visão Ampla (Zoom-Out)**: Alternância por botão no cabeçalho ou atalho `Shift+Z` para visão macro compacta de todas as semanas.
- **Sincronização em Tempo Real na Nuvem**: Atualização automática na nuvem para acesso compartilhado via GitHub Pages.
- **Menu de Contexto Completo**: Copiar (`Ctrl+C`), Recortar (`Ctrl+X`), Colar (`Ctrl+V`), Excluir (`Del`), Troca de Cores e Desfazer (`Ctrl+Z`).
- **Exportação em PDF**: Geração limpa e formatada do cronograma completo.

## 🛠️ Tecnologias
- HTML5 / CSS3 (Design System Industrial MGCEN00)
- JavaScript Vanilla (POO / DOM Event Engine)
- GitHub Pages + Cloud Sync REST API
